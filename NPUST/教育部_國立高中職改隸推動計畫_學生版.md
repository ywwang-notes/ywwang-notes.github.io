# 國立高中職改隸直轄市政府推動計畫

**課堂模擬文件｜設定時間：民國101年下半年**

> 本文件依當時的政策情境擬寫，並非教育部發布的原始計畫。甲縣正在籌備升格直轄市；文件中的甲縣、甲市與 A 國立農工均為課堂代稱。文中的工作期限屬模擬安排，實際移撥日期尚待協商。

## 一、緣起

配合縣市改制直轄市，中央研議將境內國立高中職及相關教育督導業務移交地方政府主管。改隸涉及經費、人事、校舍財產、學生就學及教育行政責任。教育部設置專責工作小組，與地方政府協商移撥事宜，並向各校蒐集移撥所需的校務資料。

本計畫旨在建立盤點及協商程序。啟動本計畫不表示甲縣已同意承接，也不表示任何學校已有確定改隸日期。

## 二、現況分析

甲縣境內已有國立高中職，也有縣立及私立學校。升格後如承接國立學校與相關督導業務，地方政府將增加高中職行政工作及支出責任；同時可以整合轄內高中職布局。各校的班級、師生、科別與設備差異，將影響承接成本。

中央目前掌握各校預算及員額資料，甲縣則須核算升格後的實際承接需求。雙方仍需釐清：原有經費是否足額移撥、教職員權益如何接續、已核定工程與未來設備更新由誰負擔。其他改制直轄市也曾因人員及經費問題延後接管；既有經驗可供比較，但不能直接取代甲縣自己的設算。

| 面向 | 盤點重點 |
| --- | --- |
| 業務範圍 | 擬移撥學校、學校類型、私校督導及教育局新增業務 |
| 經費 | 人事費、校務運作、中央補助、設備更新、重大工程 |
| 人員 | 教師與職員員額、行政人力、校長任用與退休責任 |
| 財產 | 土地、校舍、設備及在建工程的歸屬與後續維護 |
| 教育 | 招生、課程、技職實習及現行計畫的銜接 |

## 三、目標與執行策略

### 目標

1. 建立學校及移撥業務清冊。
2. 取得可逐校核對的人事、財務、財產與工程資料。
3. 蒐集地方政府承接評估及各校移撥所需的基礎資料。
4. 記錄已達共識、待補資料與仍有歧見的事項。
5. 在必要條件釐清後，協商各校移撥內容及期程。

### 執行策略

教育部向所屬國立學校彙集人事、預算、設備、財產與在建工程資料，提出初步設算並提供甲縣政府核對；甲縣政府核算承接需求，並向教育部提出資料缺口與補充需求。各校向教育部說明資料內容；如需三方共同核對，由教育部協調辦理。會商採逐項核對方式，雙方對數字或責任歸屬有不同認定時，並列計算依據及理由。跨機關或未達共識事項續行協調。

## 四、執行項目與內容

| 項目 | 辦理內容 | 形成文件 |
| --- | --- | --- |
| 啟動與分工 | 教育部函請甲縣政府評估，並向所屬國立學校調取資料；縣政府指定教育局會同財政、人事及主計單位辦理 | 承辦窗口與資料清單 |
| 學校盤點 | 教育部彙集所屬學校的師生、班級、科別、校舍、設備、預算與工程資料，提供甲縣政府核對 | 逐校現況表 |
| 財務人事設算 | 核對中央現行支出、擬移撥資源、地方預估成本及權益責任 | 雙方設算及差異表 |
| 資料補充 | 甲縣政府向教育部提出資料缺口；教育部協調所屬學校補充或說明 | 補充資料及待釐清事項表 |
| 中央地方會商 | 逐項討論業務、經費、員額、退休、財產與期程 | 會議紀錄與歧見清單 |
| 後續處理 | 處理歧見並研議學校別銜接安排 | 後續協商或移撥方案 |

甲縣政府應在承接評估中列出：可確認事項、所需補充資料、預估資源缺口、承接所需條件，以及有歧見事項的協商主張。教育部請所屬學校核對人員、預算、財產與建設資料，並彙整學校提出的資料缺漏及業務銜接資訊。

## 五、期程與資源需求

### 作業期程

以下為本模擬計畫的**階段安排**，不是已確定的改隸日期。

| 階段 | 工作 | 完成條件 |
| --- | --- | --- |
| 第一階段：資料盤點 | 教育部彙集所屬學校資料，提供甲縣政府核對 | 清冊完成，標示資料缺漏 |
| 第二階段：影響評估 | 甲縣估算承接成本，向教育部提出資料補充需求 | 取得可供核對的設算及逐校資料 |
| 第三階段：逐項會商 | 核對經費、員額、退休、財產及工程 | 記錄共識與歧見 |
| 第四階段：方案研議 | 協調未決問題，研議學校別移撥安排 | 權責機關另行確認方案與期程 |

### 資源需求

教育部與甲縣政府需投入教育行政、主計、財政、人事及財產管理人力；教育部須向所屬學校彙集預算、人員、設備與工程資料。年度移撥金額、地方新增負擔及實際行政員額均須經雙方核對，不能在本計畫啟動時預設為定數。

## 六、預期效果及影響

本計畫預期完成逐校盤點與雙方成本核算，確認可直接銜接的業務及須另行協調的問題，使學生就學、學校教學與教職員權益在主管機關變更時有可執行的安排。

如經費、人事或財產事項仍有歧見，相關機關應記錄差異、責任單位與後續協商事項，並據此評估移撥安排。最終方案及各校改隸期程，仍須由權責機關依協商結果確認。
